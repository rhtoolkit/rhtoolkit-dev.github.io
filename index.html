Welo Data Assistant Audit (Version 3.3.0)
Breakdown of what the extension monitors on RaterHub, verified by direct audit of its source code.

Welo Data Assistant is a universal tool used across multiple Welocalize partner programs. On RaterHub, invasive tracking features remain strictly disabled, as confirmed by inspecting the minified production source code.

TL;DR Conclusion

In version 3.3.0, Welo completely removed physical DOM button listeners and returned to passive background network interception (webRequest). Aggressive anti-fraud features (clipboard and keystroke tracking) remain hardcoded to false on RaterHub, and extension monitoring is blocked by the browser. Stealth automation tools remain 100% undetectable and fully synchronized.

1. Screen Recording (Sentry Replay)

The extension includes Sentry for diagnostics and error tracking. However, all form input fields on the page are strictly masked (maskAllInputs: true).

Because stealth automation tools operate with Zero DOM Injection, no foreign interface elements or modified Google forms are present in any session telemetry.

Verdict: Input Fields Masked (100% Safe)

3. Other Extension Monitoring

6. Task Submission & Network Interception

In version 3.3.0, Welo completely removed the injected DOM button listeners introduced in v3.2.0. They have returned to passive background network monitoring via chrome.webRequest.onCompleted.

Welo detects task completion by listening for the successful HTTP POST response to /evaluation/rater/task/preview*.

Is it safe to automate? Yes. When an automation tool triggers a click on Google's native submit button, the browser naturally issues the standard POST request. Welo's background service worker intercepts this network response and stops the timer in perfect sync. Concerns regarding DOM event.isTrusted checks are completely eliminated.

7. IP Location & Device Integrity

In version 3.3.0, Welo introduced passive device and network integrity checks. The extension sends a request to a third-party geolocation service (ipwho.is) to log your Internet Service Provider (ISP), country code, and geographic region.

Additionally, it creates a persistent device identifier (wda_device_token) stored in local extension storage.
