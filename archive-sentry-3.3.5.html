Welo Sentry Audit (Version 3.3.5)
What Sentry does while you use RaterHub.

← Back to the main security audit

1. What is Sentry?

Sentry is a standard tool developers use to find errors and performance problems. In this extension, it sends diagnostic information about the RaterHub page to the Welo Sentry server. Its presence alone does not mean that the screen is being recorded.

For this audit, Sentry has three relevant functions:

  • report errors;
  • measure how the page performs;
  • save a replay of the RaterHub page for some sessions.

Sentry is a standard software diagnostics tool. On RaterHub, it can save a replay of the RaterHub page for some sessions. It does not secretly film your whole screen, and the RaterHub integration does not enable the library's separate screenshot feature.

2. What is active on RaterHub?

For normal production sessions, about 10 out of 100 may receive a replay of the RaterHub page. Separately, when Sentry captures an error, the code is configured to keep the replay for that error case at a 100% sample rate. Neither setting records your monitor or other tabs.

Text that is visible on the RaterHub page may appear in the replay. Text typed into form fields is masked.

View Extension Source Code
// content-script/index.js
replaysSessionSampleRate: 0.1,
replaysOnErrorSampleRate: 1.0,
Sentry.replayIntegration({
  maskAllText: false,
  maskAllInputs: true,
  blockAllMedia: false,
});
Verdict: RaterHub webpage replay is active

3. Is the whole monitor recorded?

The active RaterHub code does not automatically record your whole screen. The 10% setting above only controls replay of the webpage.

The Sentry library also includes a standard support function for a user-requested screenshot. The RaterHub code does not turn this function on. Its presence in the library does not mean that a screenshot was taken.

Library support code (not enabled in RaterHub)
// Sentry feedback support code in the original bundle
const stream = await mediaDevices.getDisplayMedia({
  video: { width: innerWidth * scale, height: innerHeight * scale },
  audio: false,
  monitorTypeSurfaces: 'exclude',
  preferCurrentTab: true,
  selfBrowserSurface: 'include',
  surfaceSwitching: 'exclude',
});

If this standard support function were used, Chrome or Edge would normally ask what to share. No active RaterHub call to it was found.

Verdict: No automatic whole-screen recording found
