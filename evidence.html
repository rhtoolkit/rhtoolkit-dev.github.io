Method and provenance

Website baseline: repository commit c4ddb3f. Extension comparison: preserved local packages 3.3.5, 3.4.0 and 3.4.1. The 36 copied 3.4.1 package files matched the installed files by SHA-256 at audit time.

Source maps embedded in the distributed bundles supplied original source text. Among recoverable own-source modules, the 3.4.0 → 3.4.1 comparison found 60 unchanged, 8 modified and 11 added. Among 255 dependency modules recovered from those maps, 250 were unchanged and 5 changed. These counts are not a count of every file in the upstream project. Principal changes were also checked in compiled code.

The excerpts below are copied verbatim from the recovered 3.4.1 sources, with original line numbers. Hashes identify the complete extracted source text used for each excerpt; they are not package signatures. Excerpts are selected for this audit and are not standalone programs.

Four earlier isolated checks covered payloads, validation and error/blocking paths. Eight further local scenarios passed: equivalent Sentry options, identity retries without login/acceptance, four automatic-lookup gate combinations, synthetic email caching, and restoration of Submit controls. APIs were simulated; no live account, real task content or backend was exercised. Test inputs and personal browser data are not published here.
